# Передача бота заказчику — локальный компьютер (инструкция для разработчика)

## Сценарий

Вы настраиваете бота у себя с токенами заказчика, затем передаёте готовую папку.
Заказчику остаётся только установить Python и запустить `py main.py`.

---

## Что попросить у заказчика

| Что | Где взять |
|---|---|
| Токен MAX-бота | Создать бота на dev.max.ru, скопировать токен |
| Токен Яндекс.Диска | Создать OAuth-приложение на oauth.yandex.ru (инструкция ниже) |
| Токен ngrok | Зарегистрироваться на ngrok.com, раздел "Your Authtoken" |
| Файл номенклатуры | Excel-файл с товарами заказчика |
| Подпись.png, Печать.png | Их изображения (или оставить ваши, если подходят) |

### Как заказчику получить токен Яндекс.Диска

1. Зайти на oauth.yandex.ru под аккаунтом организации
2. Зарегистрировать приложение: платформа — Веб-сервисы, Redirect URI — `https://oauth.yandex.ru/verification_code`
3. Права: `cloud_api:disk.read`, `cloud_api:disk.write`
4. Скопировать Client ID и открыть в браузере:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`
5. Разрешить доступ — токен появится в адресной строке

## Что делаете вы

### 1. Загрузить файлы на Яндекс.Диск заказчика

Используя их токен, загрузить через браузер (disk.yandex.ru) или через API:
- `template.xlsx` → `/КП/template.xlsx`
- `nomenclature.xlsx` → `/КП/nomenclature.xlsx`

### 2. Настроить .env с токенами заказчика

```
MAX_BOT_TOKEN=токен_заказчика
YANDEX_DISK_TOKEN=токен_яндекс_диска_заказчика

YANDEX_DISK_TEMPLATE_PATH=/КП/template.xlsx
YANDEX_DISK_NOMENCLATURE_PATH=/КП/nomenclature.xlsx
YANDEX_DISK_GENERATED_FOLDER=/КП/generated

DATABASE_PATH=bot.db
NGROK_AUTH_TOKEN=токен_ngrok_заказчика
```

### 3. Проверить работу у себя

Запустить `py main.py` и отправить тестовую заявку в MAX.
Убедиться, что КП генерируется и сохраняется на Яндекс.Диске заказчика.

### 4. Собрать архив для передачи

```powershell
cd "папка-с-ботом"
```

Включить в архив:
- Весь код (все .py файлы, requirements.txt, .gitignore)
- `.env` (уже с токенами заказчика)
- `Подпись.png`, `Печать.png`

Не включать: `bot.db`, `__pycache__`, временные файлы.

## Нюанс с ngrok

Бесплатный аккаунт ngrok = 1 активный туннель. Пока вы тестируете с токеном заказчика,
ваш собственный ngrok не работает. Удобнее: протестировать со своим токеном,
убедиться что всё работает, затем заменить `NGROK_AUTH_TOKEN` на токен заказчика и передать.
