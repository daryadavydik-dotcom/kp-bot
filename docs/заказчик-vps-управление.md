# КП-бот на сервере — инструкция для заказчика

Разработчик уже настроил всё на сервере. Бот работает автоматически 24/7.
Эта инструкция — на случай если нужно проверить статус, перезапустить или обновить бота.

---

## Как создать сервер (если ещё не создан)

### Шаг 1. Выбрать хостинг и зарегистрироваться

Рекомендуемые провайдеры:

| Провайдер | Цена | Сайт |
|---|---|---|
| Timeweb | от 250 ₽/мес | timeweb.com |
| REG.RU | от 300 ₽/мес | reg.ru |
| Hetzner | от 350 ₽/мес | hetzner.com |

Для бота достаточен самый дешёвый тариф: **1 CPU, 1 GB RAM**.

### Шаг 2. Создать сервер (на примере Timeweb)

1. Войти в личный кабинет → **Облачные серверы** → **Создать сервер**
2. Выбрать:
   - Операционная система: **Ubuntu 22.04**
   - Тариф: минимальный
3. Нажать **Создать**
4. На почту придёт письмо с **IP-адресом**, **логином** (`root`) и **паролем**

### Шаг 3. Передать данные разработчику

Отправьте разработчику:
- IP-адрес сервера
- Пароль от сервера
- Токен вашего MAX-бота
- Токен Яндекс.Диска

После того как разработчик всё настроит — **смените пароль от сервера** в личном кабинете хостинга.

## Подключение к серверу (для управления)

### На Windows

1. Открыть терминал PowerShell (кнопка Пуск → "Windows PowerShell")
2. Ввести:
   ```
   ssh root@IP_АДРЕС_СЕРВЕРА
   ```
3. Ввести пароль (при вводе символы не отображаются — это нормально)

---

## Основные команды

**Проверить, работает ли бот:**
```bash
systemctl status kp-bot
```
Должно быть написано `Active: active (running)`.

**Перезапустить бота:**
```bash
systemctl restart kp-bot
```

**Остановить бота:**
```bash
systemctl stop kp-bot
```

**Запустить бота:**
```bash
systemctl start kp-bot
```

**Посмотреть последние логи (если что-то не работает):**
```bash
journalctl -u kp-bot -n 50
```

---

## Что делать если бот не отвечает

1. Подключиться к серверу (см. выше)
2. Выполнить:
   ```bash
   systemctl restart kp-bot
   ```
3. Подождать 10-15 секунд и проверить в MAX

Если не помогло — отправить разработчику вывод команды:
```bash
journalctl -u kp-bot -n 100
```

---

## Важно знать

- Бот запускается автоматически при включении/перезагрузке сервера
- Все готовые КП сохраняются на Яндекс.Диске в папке `/КП/generated/`
- Сервер нужно **оплачивать ежемесячно** — при неоплате хостинг его удалит вместе с ботом
- SSL-сертификат (HTTPS) обновляется автоматически раз в 3 месяца
