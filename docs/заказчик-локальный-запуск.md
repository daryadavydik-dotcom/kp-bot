# Запуск КП-бота — инструкция для заказчика (локальный компьютер)

Разработчик уже настроил всё за вас. Вам нужно только установить Python и запустить бота.

---

## Что вы получите от разработчика

- Архив с папкой бота (уже настроен, токены внутри)
- `Подпись.png`, `Печать.png` — изображения для КП

---

## Шаг 1. Установить Python

1. Скачать Python 3.11: https://python.org/downloads
2. При установке поставить галочку **"Add Python to PATH"** — это важно
3. Нажать Install, дождаться завершения

---

## Шаг 2. Установить ngrok

1. Зарегистрироваться на https://ngrok.com (бесплатно)
2. Скачать ngrok для Windows, разархивировать
3. Файл `ngrok.exe` положить в папку с ботом

---

## Шаг 3. Распаковать бота

1. Распаковать архив от разработчика в удобную папку, например `C:\КП-бот\`
2. Убедиться, что в папке есть файл `.env` (он может быть скрытым — включить отображение скрытых файлов в Проводнике: Вид → Показать → Скрытые элементы)

---

## Шаг 4. Установить зависимости

1. Открыть терминал в папке бота: в Проводнике правая кнопка на пустом месте → **"Открыть в терминале"**
2. Ввести команду и нажать Enter:
   ```
   py -m pip install -r requirements.txt
   ```
3. Подождать завершения (может занять 1-2 минуты)

---

## Шаг 5. Запустить бота

В том же терминале:
```
py main.py
```

Если всё настроено правильно, появится:
```
BOT STARTED
Webhook URL: https://xxxx.ngrok-free.app/webhook
Webhook registered successfully!
```

Бот работает. **Не закрывайте терминал** — пока он открыт, бот принимает заявки.

---

## Как перезапустить бота (если завис или не отвечает)

Выполнить в терминале:
```
Stop-Process -Name ngrok,python -Force -ErrorAction SilentlyContinue
py main.py
```

---

## Важно знать

- Бот работает только пока включён компьютер и открыт терминал
- При каждом запуске адрес вебхука меняется — это нормально, бот обновляет его автоматически
- Готовые КП сохраняются на вашем Яндекс.Диске в папке `/КП/generated/`
- Если нужна работа 24/7 без участия человека — потребуется перенос на VPS-сервер
