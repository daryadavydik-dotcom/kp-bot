# Статус проекта: КП-бот для MAX

## Что сделано

- Бот запускается и принимает сообщения через MAX ✓
- Вебхук регистрируется автоматически при старте ✓
- Номенклатура загружается с Яндекс.Диска (`/MFB/data/nomenclature.xlsx`) ✓
- Шаблон КП берётся с Яндекс.Диска (`/MFB/templates/kp_template_v2.xlsx`) ✓
- Сгенерированные КП сохраняются в `/MFB/kp/` ✓
- SQLite база данных для хранения незавершённых заявок ✓

## Как запустить

1. Открыть терминал в VS Code (`` Ctrl+` ``)
2. Выполнить: `py main.py`
3. Бот запустится, зарегистрирует вебхук и будет ждать сообщений

## Файлы проекта

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа, запуск ngrok + бот |
| `max_bot.py` | Webhook-сервер, отправка сообщений в MAX |
| `handlers.py` | Логика обработки сообщений |
| `config.py` | Конфигурация из .env |
| `database.py` | SQLite: незавершённые заявки, счётчик КП |
| `yandex_disk.py` | Работа с Яндекс.Диском |
| `logic/prepare_kp.py` | Поиск товаров в номенклатуре |
| `logic/client_data.py` | Проверка данных клиента |
| `logic/merge_answer.py` | Объединение ответа оператора с заявкой |
| `logic/build_kp.py` | Заполнение шаблона Excel |

- Для постоянной работы нужен VPS сервер

## Команды бота

- `/start` — приветствие
- `/cancel` или `отмена` — отменить текущую заявку
- `/reload` — перезагрузить номенклатуру с Яндекс.Диска
